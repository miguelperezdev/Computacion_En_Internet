## 📘 Descripción General

Este repositorio reúne los **laboratorios, tareas y proyecto final** desarrollados durante el curso **Computación en Internet I**.  

El curso introduce los **fundamentos de redes de computadores** y la **programación de aplicaciones distribuidas**, proporcionando las bases para entender cómo los sistemas se comunican a través de Internet y cómo se construyen aplicaciones cliente-servidor y web.

---

## 🎯 Objetivo del Curso

Diseñar, implementar e integrar **aplicaciones distribuidas sencillas** cuyos componentes puedan comunicarse mediante mecanismos básicos de red, además de comprender el funcionamiento de **HTTP** y la estructura de páginas web con **HTML y CSS**.

---

## 🧠 Competencias Desarrolladas

Durante el curso se fortalecieron habilidades para:

- Analizar y comprender la arquitectura de redes de computadores  
- Resolver problemas de comunicación entre sistemas distribuidos  
- Diseñar soluciones cliente-servidor funcionales  
- Implementar aplicaciones que intercambian información mediante protocolos de red  
- Entender las bases tecnológicas de la Web  

---

## 🌐 Temas Trabajados

### 🔹 Fundamentos de Redes
- Modelo **OSI** y funciones de sus capas  
- Direccionamiento **IPv4** y conceptos básicos de **IPv6**  
- Topologías de red  
- Dispositivos y elementos de infraestructura de red  

### 🔹 Comunicación en Red
- Protocolos de transporte **TCP y UDP**  
- Uso de **sockets** para comunicación entre procesos  
- Herramientas de diagnóstico de red  

### 🔹 Programación en Internet
- Modelos **Cliente/Servidor**, **P2P** y **Web**  
- Desarrollo de aplicaciones distribuidas  
- Uso de **middleware** para comunicación entre componentes  
- Fundamentos de **HTTP/HTTPS**  
- Creación de páginas web con **HTML y CSS**  
- Consumo de **APIs REST** usando **JSON**

---

## 🛠️ Tecnologías Utilizadas

- **Java** – Programación con sockets y aplicaciones distribuidas  
- **Node.js** – Desarrollo de servidores y servicios REST  
- **HTML5 & CSS3** – Estructura y diseño de páginas web  
- **HTTP** – Protocolo de comunicación web  
- **JSON** – Intercambio de datos en servicios web  


---

## 🚀 Proyecto Final

El proyecto final integra los conocimientos adquiridos mediante el desarrollo de una **aplicación distribuida**, en la cual se implementa:

- Comunicación entre cliente y servidor  
- Intercambio de datos a través de protocolos de red  
- Componentes desplegables de manera independiente  
- Interacción con servicios web  

Este proyecto evidencia la aplicación práctica de los conceptos de **sistemas distribuidos** y **programación en Internet**.
