# 🎵 Taller Spring Discography

Aplicación web para la gestión de una discografía musical.

**Esta rama contiene la versión implementada usando Annotations para la configuración de Spring.**  
Las demás versiones del proyecto (por ejemplo, configuración XML u otras variaciones) se encuentran en sus respectivas ramas.

---

## Tecnologías utilizadas

- **Jakarta EE 10** (Servlet 6.0, JSP)
- **Spring Framework 6** (Inyección de dependencias con Annotations)
- **Apache Tomcat 11**
- **Maven**
- **Java 17**
