🎉 ¡Servidor HTTP Funcionando!

Este es un servidor web multihilo escrito en Java que cumple con todos los requisitos:

✅ Características implementadas:

  • Escucha en puerto configurable (>1024)
  • Arquitectura multihilo (un hilo por solicitud)
  • Soporte HTTP/1.0 con método GET
  • Muestra solicitudes por consola
  • Respuestas HTTP válidas con CRLF
  • Soporte para HTML, JPG, GIF y más
  • Manejo de errores 404
  • Cierre seguro de recursos

🔗 Enlaces de prueba:

  • Página principal (esta)
  • Página de prueba
  • Recurso inexistente (404)
